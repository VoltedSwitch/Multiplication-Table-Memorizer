# Release Notes

## v0.1.0 — 2026-10-21

First release of Multiplication Table Memorizer, a terminal app for practicing multiplication facts.

### What’s new in v0.1.0

- Choose a number and practice its multiplication table from 1 through 10.
- Preview each answer for three seconds, followed by a five-second recall countdown.
- Enter each product from memory; incorrect answers can be retried until correct.
- Earn a point for each correct answer and track progress toward completing the table.
- Start another table after finishing, or quit the program.
- Use ANSI styling and terminal cursor and screen controls for a focused quiz view.
