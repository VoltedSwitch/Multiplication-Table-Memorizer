# ✖️ Multiplication Table Memorizer 🧠

Practice a multiplication table with quick previews and a recall quiz. Build confidence one answer at a time! 🎯

## 🚀 Get started

**Requirements:** Python 3.10 or newer and a terminal that supports ANSI escape codes.

From the project directory, start the program with:

```bash
python3 main.py
```

## 🎮 How to play

1. Enter the number whose table you want to practice.
2. Review each answer when it appears, then try to remember it.
3. Enter the product when prompted. If it’s incorrect, you can try again.
4. Complete the table from 1 to 10. Press **Enter** to practice another table, or type **q** to quit. 🏆
